# Instruction Set Simulator

A web-based Instruction Set Simulator developed for the Computer Organization and Architecture course.

## Features

- Generates 3-Address Instructions
- Generates 2-Address Instructions
- Generates 1-Address Instructions
- Generates 0-Address Instructions
- Supports arithmetic expressions with:
  - +
  - -
  - *
  - /
  - Parentheses
- Simple and interactive web interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Enter an arithmetic expression.
4. Click **Generate** to view the instruction formats.
